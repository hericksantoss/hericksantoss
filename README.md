## Projeto em destaque

### [Pipeline de indicadores do Banco Central](https://github.com/hericksantoss/pipeline-indicadores-bcb)

Pipeline de ponta a ponta que coleta dólar, euro, Selic e IPCA da API do Banco Central e organiza os dados em
camadas **bronze → silver → gold**. Ele tem carga incremental, checagens de qualidade antes de gravar e uma camada gold
escrita em SQL com window functions. Roda sozinho todo dia útil no GitHub Actions e publica os indicadores
atualizados no próprio README.
